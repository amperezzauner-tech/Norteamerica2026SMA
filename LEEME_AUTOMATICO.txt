AUTOMATIZACIÓN DE RESULTADOS — POLLA NORTEAMÉRICA 2026

Qué hace esto:
- GitHub Actions corre cada hora.
- Consulta API-Football / API-SPORTS.
- Si encuentra partidos finalizados, edita resultados.json.
- Hace commit automático.
- GitHub Pages actualiza la página sola.

Archivos nuevos importantes:
1. actualizar_resultados.py
2. .github/workflows/actualizar-resultados.yml

PASOS EN GITHUB

1. Sube TODOS los archivos de este ZIP a la raíz del repositorio.
   Muy importante: la carpeta .github debe quedar así:
   .github/workflows/actualizar-resultados.yml

2. Crea la llave de API-Football:
   - Entra a https://www.api-football.com
   - Crea cuenta gratuita.
   - Copia tu API key.

3. Guarda la llave en GitHub:
   - Repositorio Norteamerica2026SMA
   - Settings
   - Secrets and variables
   - Actions
   - New repository secret
   - Name: API_FOOTBALL_KEY
   - Secret: pega tu API key
   - Save

4. Dale permiso al workflow para escribir:
   - Settings
   - Actions
   - General
   - Workflow permissions
   - Selecciona: Read and write permissions
   - Save

5. Prueba manual:
   - Entra a Actions
   - Selecciona: Actualizar resultados de la polla
   - Run workflow
   - Espera a que termine.

6. Revisa resultados:
   - Abre resultados.json en GitHub.
   - Si había partidos nuevos finalizados, debe aparecer un commit automático.
   - Abre tu página y recarga.

Notas:
- El plan gratis de API-Football suele alcanzar para una consulta por hora.
- Si no actualiza, revisa la pestaña Actions para ver el error.
- Si el Mundial usa otro league_id diferente a 1, cambia API_FOOTBALL_LEAGUE_ID en el workflow.
