OPCIÓN 3 — Actualización automática sin API-Football

Qué hace:
- Usa el marcador público de ESPN.
- No necesita API key.
- Corre cada hora con GitHub Actions.
- Actualiza resultados.json y hace commit automático.

Qué debes subir/reemplazar:
1. actualizar_resultados.py
2. .github/workflows/actualizar-resultados.yml

Luego:
1. Ve a Settings → Actions → General.
2. En Workflow permissions marca Read and write permissions.
3. Ve a Actions → Actualizar resultados de la polla.
4. Run workflow.

Ya NO necesitas el secret API_FOOTBALL_KEY.
